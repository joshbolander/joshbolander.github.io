# Software Design and Engineering

## Artifact Overview

This artifact originated as the WeightTracker Android application developed
during CS 360. For this enhancement, I transformed the application into a
more realistic Cardiac Rehabilitation Tracker while improving its design,
organization, usability, and maintainability.
